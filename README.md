# Agentic AI — Multi‑Cloud Agentic Systems (Azure, AWS, GCP)

A professional, end‑to‑end agentic AI engineering portfolio demonstrating how to build
agentic systems across multiple cloud platforms. Each cloud implementation follows the
same 3‑day structured roadmap:

1. **Day 1 — Extraction + Embeddings + Vector Search**
2. **Day 2 — Knowledge Graph + Entity Resolution**
3. **Day 3 — LangGraph Agent + Tool Orchestration**

This repository is designed to showcase practical agentic AI engineering skills expected
in modern AI Engineer – Agentic Systems roles.

---

## 🎯 Project Goal

Build fully functional agentic AI systems capable of:

- Reading and understanding documents  
- Extracting entities and relationships  
- Storing embeddings for semantic search  
- Building and querying knowledge graphs  
- Using LangGraph to orchestrate tools  
- Producing final answers using multi‑source reasoning  

Each cloud implementation demonstrates the same agentic workflow using cloud‑native
services.
